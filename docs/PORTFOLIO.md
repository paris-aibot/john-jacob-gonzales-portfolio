## 1. Portfolio descriptions

### Short (≈50 words)
> A zero-dependency personal portfolio for a railway Testing & Commissioning Engineer, built in hand-written HTML, CSS, and vanilla JavaScript. Features a custom "transit/HUD" design system, full accessibility (WCAG AA, keyboard, reduced-motion), progressive enhancement, SEO/structured data, a print-to-PDF résumé mode, and CI/CD deployment to Cloudflare Pages.

### Medium (≈150 words)
> A production-grade personal portfolio site engineered without frameworks — just semantic HTML5, modern CSS, and a small amount of vanilla JavaScript. The page presents an unusual career blend (railway commissioning, live train operations, and workplace safety) through a custom "transit/HUD" design system driven by CSS custom properties.
>
> Beyond visuals, the project is built to professional standards: content is fully accessible without JavaScript (progressive enhancement), meets WCAG AA color contrast, includes keyboard focus management, a skip link, and `prefers-reduced-motion` handling. It ships SEO and social metadata (Open Graph, Twitter cards, JSON-LD `Person` schema), a sitemap, a friendly 404 page, and a print stylesheet that turns the page into a clean downloadable résumé.
>
> Security headers (CSP and friends) and CI/CD are configured for Cloudflare Pages via GitHub Actions, with full documentation, contribution guidelines, and an MIT license — a complete, deployable repository rather than a single loose file.

### Long (≈300 words)
> This is a personal portfolio website built as a deliberately framework-free, single-file engineering exercise — proving that a fast, accessible, professional site needs no build pipeline or npm dependency tree. It's authored in semantic HTML5, modern CSS (custom properties, Grid, fluid `clamp()` typography), and a small footprint of vanilla JavaScript.
>
> The subject is an unusual, intentional career profile: a Testing & Commissioning Engineer who is also a certified Train Operator and an Associate Safety Officer on the Philippines' MRT-7 line, now expanding into process automation and AI tooling. The design expresses this with a custom "transit/HUD" visual language — monospaced system labels, scan-line textures, status indicators, and a restrained cyan-on-near-black palette — all centralized as design tokens for maintainability.
>
> The project was taken through a full production-readiness pass. Accessibility: WCAG AA contrast, visible keyboard focus rings, a skip-to-content link, ARIA labelling, and `prefers-reduced-motion` support. Resilience: scroll-reveal animations are progressively enhanced so that, unlike the original version, **all content remains visible with JavaScript disabled**. Discoverability: complete SEO and social metadata, JSON-LD structured data, `robots.txt`, and `sitemap.xml`. Usability: sticky navigation with scroll-spy, a back-to-top control, and a print stylesheet that exports the page as a recruiter-ready PDF résumé.
>
> It's packaged as a real open-source repository: README with architecture notes, deployment guide, MIT license, contribution and security policies, code of conduct, issue/PR templates, and a GitHub Actions workflow that deploys to Cloudflare Pages on every push — with CSP and security headers enforced at the edge. The result demonstrates front-end fundamentals, accessibility literacy, performance awareness, security hygiene, and end-to-end ownership from code to deployment.
>
